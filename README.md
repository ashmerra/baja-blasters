# Baja Blasters

Part the Red Team. A portrait phone browser game.

**Play: https://ashmerra.github.io/baja-blasters/**

Drag and steer Moses. Grab Baja Blast to keep the Dew flowing. Tap **BAJA BLAST** to clear the sea.

Run locally: `scripts/serve.py`, then open http://127.0.0.1:8790/
